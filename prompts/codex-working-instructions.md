# Instrucciones complementarias para Codex

Seguí `AGENTS.md` como fuente de reglas del repositorio.

Tu trabajo es **construir la experiencia visual de Able**: Blender, materiales, rigging, expresiones, animaciones, runtime y futura integración del widget de voz oficial de Able.

No desarrolles un agente conversacional, backend LLM ni servicios STT/TTS. El XML en `able-reference/` es respaldo de la configuración de Able, no algo que debas ejecutar localmente.

La documentación del widget está pendiente: no inventes métodos ni eventos. Podés producir esquemas, interfaces o mocks marcados como tales; pedí el snippet real antes de integrar.

Al realizar cambios, explicá decisiones y verificaciones con precisión.
